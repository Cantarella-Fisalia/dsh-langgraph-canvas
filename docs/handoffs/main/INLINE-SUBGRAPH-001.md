# INLINE-SUBGRAPH-001：在当前画布展开图调用

日期：2026-10-27。负责方：甲方。状态：甲方交付完成，待乙方 Electron 桌面验收。

用户要求点击双线框后，用大容器包住展开的子图。实现为同一 React Flow 画布的父子容器：外层调用节点保留原 ID 和进出边，内部图用独立实例 ID，保留其 START／END、条件菱形和实际边；直接注册子图与函数内部调用继续区分。展开只影响显示，不把内部边注册到外层源码。

展开时临时自动避让布局，暂停拖动和保存布局；收起恢复原有位置和未保存状态。框内节点／边按所属图查看详情与证据，不进入外层编辑目标；需要修改时单独打开对应图。支持显式逐层展开，阻止循环展开并设置深度／节点上限，保留单独打开入口。普通展开不调用模型、不读写业务源码。

范围：前端画布、纯展示投影、基本测试、运行测试清单及主设计／使用／交接说明。不改 Harness 适配器、插件清单、协议、profile、用户项目源码或依赖。版本沿用宿主包 v0.6.7，主计划 v0.29。
