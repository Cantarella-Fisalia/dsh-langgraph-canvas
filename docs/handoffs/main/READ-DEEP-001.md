## 实现与边界

- Symbols 在项目内追踪模块／函数导入、try 导入、多级转发、常量与有限字面量注册表；继承 State 展开，不导入／执行 Python。最多扫描 2000 个 Python 文件，业务优先；辅助函数 builder 调用等未支持写法显式诊断。
- 参考目录 docs/doc/examples/example/tests/test/archive 相对于所选根目录分类；默认只展示业务图，可勾选参考，目录分类暂无自定义覆盖。根目录、计数、来源、不完整与只读原因直接显示。
- 静态字面量注册循环可读取但暂不写回。前端隐藏其结构编辑，Python 源码转换再拒绝；动态不完整图同样只读。AI 推断不会成为源码事务权威。
- 新 analysisAdapter 使用真实 ctx.llm.stream 与全局默认模型，tools:[]；前端单独确认按钮才创建任务。后端代读索引内源码、校验已读区间与版本、保存派生缓存。模型输出源位置正确不等于语义正确，所有 AI 图均只读。预算／取消／缓存限制详见 [API](../../api/DEEP_ANALYSIS_API.md)。
- 任务当前在内存，退出不重发；同版本已完成缓存保留。取消停止等待与后续结果处理，提供方未必退还已计费用量。已经开始的合法缓存写入可能在取消时完成，但不写项目源码。未接入任意动态 Python 执行恢复、源码任意重构或自动父子图嵌套。
