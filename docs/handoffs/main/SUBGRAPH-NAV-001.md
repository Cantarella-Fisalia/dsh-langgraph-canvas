# SUBGRAPH-NAV-001：通过按钮跳转子图并返回来源

日期：2026-10-28。负责方：甲方。状态：主功能已实现，待桌面验收。

用户明确取消内嵌展开。删除同画布容器交互及相关展示代码；点击调用节点仅查看详情，点击“展开子图”按钮才切换到目标图。目标图提供“返回”并按真实进入路径逐级回到来源，不猜测主图。多目标各有按钮；未核对目标时不猜测或自动请求 AI。

导航在当前页面内临时保留各图的真实节点位置、未保存标记、缩放／平移、选中项和布局版本，返回时恢复；不自动保存布局、不写源码。跨项目或源码版本变化清空临时导航。下拉选择图开启新的浏览路径，已有各图临时视图仍保留在当前作用域。

本批维护前端、基本检查与设计／使用／交付说明，不改 Harness 适配器、清单、profile、业务项目或协议。主计划 v0.30，宿主包仍 v0.6.7。完整检查与桌面复测边界交付时补全。
