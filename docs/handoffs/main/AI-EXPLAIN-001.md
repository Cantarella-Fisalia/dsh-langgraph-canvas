# AI-EXPLAIN-001：面向初学者的架构解读

2026-10-26，甲方主功能完成并交付试用，插件 v0.5.0，主计划 v0.19。用户要求让大模型补充图之间关系、业务入口／出口、State 变量意义与实际分支条件；节点按注册对象标注，不把函数内部调用多个辅助函数误称“函数组”。

本批采用独立的有源码证据的 AI 解读层，附加到已有静态结构；不因补充说明将完整静态图改成推断图，不修改项目源码。沿用明确确认的 AI 解析通道、缓存版本、取消、预算和无工具限制，扩展提示与验证协议，新增图关系／输入输出说明／State 释义／节点实现类别／条件说明的界面。未覆盖项明确提示待解读，不能编造联系或数据。

范围：apps、packages/contracts、services/python-worker、plugins/harness 的必要提示适配、测试、主计划与使用文档。实际 IntentNavi 仅只读参考，不执行／导入或改其源码，不调用用户账号。先隔离验证，再按摘要检查同步 E:/Heng/vis4agent；不改乙方记录或桌面 profile。

## 实现

新增 ArchitectureExplanation 协议和 Python 校验器 explanations.py。模型可按需追踪跨文件调用、输入包装函数、State 定义与实际路由，返回独立 architecture；每条文本须有已读取的证据区间，引用必须对应已知图／节点／字段／条件边。完整静态图保留，说明不改其结构、源码或写回权限。缓存仍按项目源码版本绑定，读取时重新校验解释证据；旧缓存无解释时明确提示重新分析，不自动调用模型。

界面新增“看懂这套流程”：图用途、图关系按钮与调用链证据、当前图业务输入／输出、条件总览；共享 State 增加字段中文用途、输入／中间／输出角色、已确认读写节点。画布条件短标签可悬停查看全文，侧栏有真实判断与证据。点击证据定位源码并高亮；未解读字段／条件计数与缺项可见，不声称全覆盖。解读说明绑定已保存源码，排除本地草稿。

GraphNode.execution=function/callable/subgraph/unknown；静态确认的函数节点不能被 AI 改标成子图或可调用链。函数内部多个调用列入 calls，仍是函数节点。间接调用关系要求来源节点与多处调用链证据；与直接注册子图区分。START/END 标明虚拟边界，业务输入输出另由包装函数解释。新增静态 routerSource 与 State.source 便于直接定位。

定义参考：[LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api)、[Subgraphs](https://docs.langchain.com/oss/python/langgraph/use-subgraphs)。用户实际 IntentNavi 三张业务图 17 个节点均直接注册函数，保留函数称呼；没有为 IntentNavi 在产品代码中硬编码业务说明。

## 试用与限制

完全退出重开桌面 Harness，确认 v0.5.0，打开 IntentNavi 架构，点“用 AI 解释架构”／“更新 AI 解读”，核对默认模型，再明确开始。旧版缓存没有新版说明，需要一次明确重新分析。单次最多六轮／五分钟，可能只解释部分内容，以覆盖计数和待确认项为准；失败保留静态结构，原源码不变。

证据校验只核对位置、版本与引用，不证明文字语义或调用链一定正确；所有说明显示 AI 解读。模型账号实际可用性、完整解释质量与 Electron 桌面试用待用户反馈。注册表图及 AI 推断图的源码编辑限制保持不变；本次不实现任意函数组自动重构、运行追踪或自动父子图画布嵌套。
