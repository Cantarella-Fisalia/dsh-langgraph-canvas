# CANVAS-SESSION-001：画布优先与当前会话 AI

2026-10-26，甲方交付 v0.6.0，主计划 v0.20。用户明确要求：State 放入图内左上角、点击展开；删除“看懂这套流程”整块；入口出口附在图中；AI 缩为小按钮或自动化；AI 请求通过当前 Harness 会话，使用该会话的模型。

实现选择：保留小按钮，点击即明确提交本会话解读任务；不在打开图时自动计费调用。State 作为画布浮动控件，入口／出口附在 START／END，详情按需展开；诊断、读取范围与任务状态压缩为按需查看。图关系说明可保留在按需详情，删除原大面板。

AI 接入改为真实 Session 提示／Agent 会话事件流，保留对话上下文与会话模型路由，不把“同一个模型的独立 llm.stream”冒充调用会话。需在任务期间按本次会话回合限制工具，避免解释直接修改原项目；普通会话不受全局限制。确认写回／撤销仍独立。覆盖解析与节点行为两类 AI 调用，所有请求携带当前 sessionId，幂等、取消和错误状态保留。

范围：前端画布、宿主上下文桥接、会话调用适配、API／协议／worker 必要会话元数据、测试与主文档。只读检查已安装 Harness vendor 代码；不改其源码、生产 profile 或 IntentNavi 源码，不调用用户账号进行验收。隔离实测后按基线摘要同步 E:/Heng/vis4agent。用户后续指令授权本批必要接入层调整，乙方记录保持不变。

## 已实现

- CanvasState 在 React Flow 的 top-left Panel 内，默认折叠，先选择变量含义／读写关系／源码定义，再选具体字段；保留变量原名、原类型、AI 不确定性及证据。
- 删除 ArchitecturePanel、旧 StatePanel 和大 AI 面板。START／END 显示业务输入／输出简述，点击详情看全文与证据。来源、诊断及状态收起；画布占主要空间，主题继续沿用 Harness。
- 小“✦ AI”按钮点击即明确提交，普通打开／刷新／展开 State 不调用模型；运行中再点取消。回执不确定时保留同一请求号，避免重复调用。
- 宿主桥接携带当前 sessionId，切换同工作区的会话也更新。解读和节点行为请求均经 sessionController.inspect／resolveAgent 取得原生 Agent，再调用公开 Agent.followup（SessionController.prompt 内部同一提示入口）。回复来自当前会话事件，沿用真实上下文与模型，进入原对话历史。
- 插件回合通过 system-prompt/assemble 隐去工具，并注册 Agent 作用域单调 tools.guard；拒绝工具型回复、超长、异常、中断。完成清理钩子与租约，普通回合恢复工具。用户 steer 消息移到其普通下一轮，不混入解读或丢弃；取消只操作本插件拥有的消息／回合，保留其他队列。
- 会话忙碌时不新提交；已有行为任务仍能监视和取消。原项目写入继续走受限副本、差异审阅、单独确认应用和撤销。缓存证据／源码版本校验不变。

## 验证与边界

99 项自动检查（48 Node＋51 Python）、类型检查、构建与 11 项插件预检通过。增加会话独占、工具隔离及释放、错误注册回收、取消不丢用户输入、steer 延后等测试；已有源码应用／精确撤销检查继续通过。

实际安装的 Harness 原生运行时在独立 DSH_HOME/profile 中使用确定性测试提供方：全局默认 global-only、会话选择 conversation-only，确认解读和行为副本写入均使用后者；已有 CONTEXT_MARKER 历史可见、任务和回复写入同一会话。插件轮工具为空，普通下一轮恢复 32 项工具；工具回复拒绝、取消后再请求成功。实际行为 adapter 只写自有临时副本，结束后已清理。

原生页面 DOM 验证：三业务图可切换，State 默认折叠且选择 route_b 后显示已知读写节点，START／END 有说明，无“看懂这套流程”或大 AI 面板；图画布约 450px／iframe 538px 高。小按钮已实际提交到当前会话，页面显示完成，原对话可见 JSON 回复，所选模型为 Conversation fixture。浏览器截图接口本轮返回 Unable to capture screenshot，故保存 DOM 与结构化证据，不宣称完成像素验收。证据见 CANVAS-SESSION-001-evidence.json 及 CANVAS-SESSION-001-ui-dom.md。

假模型用于接口和安全边界验证，不代表用户账号的解释质量／模型遵循 JSON 的稳定性。没有重启生产桌面。Harness 升级后若缺少会话或工具隔离接口会明确拒绝，不回退到独立默认模型。会话历史包含源码与 JSON，可能增加上下文用量；最多六轮预算仍生效。overview／relationships 仍保留缓存协议，本版无独立大概览／关系面板。

用户试用：完全退出重开 Harness，在项目会话中选模型 → 架构 → 点 State 按需看字段 → 点击小 AI 解读 → 回对话查看任务和回复。会话忙碌先等待；修改代码仍需原来的审阅确认链。无需 GitHub 或重新安装链接插件。
